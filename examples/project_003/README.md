## 📁 文件说明

- `generate_keyframes.py`: 关键帧生成脚本（20 张）
- `generate_videos.py`: 视频片段生成脚本（10 段）
- `generate_srt.py`: SRT 字幕生成脚本
- `generate_tts.py`: TTS 配音生成脚本
- `subtitles.srt`: 字幕文件（10 条）
- `narration.mp3`: TTS 配音（288KB）
- `video_final.mp4`: 最终视频（15MB）

---

## 🚀 使用方法

### 1. 生成关键帧

```bash
python3 generate_keyframes.py
```

输出：20 张关键帧（1920x1920）

### 2. 生成视频片段

```bash
python3 generate_videos.py
```

输出：10 段视频（3-10 秒各不同）

### 3. 生成字幕

```bash
python3 generate_srt.py
```

输出：`subtitles.srt` (10 条字幕)

### 4. 生成 TTS 配音

```bash
python3 generate_tts.py
```

输出：`narration.mp3` (288KB, 36 秒)

### 5. 合并视频

```bash
# 合并视频片段
cd videos
for f in *.mp4; do echo "file '$f'"; done > concat_list.txt
cd ..
ffmpeg -f concat -safe 0 -i videos/concat_list.txt -c copy video_merged.mp4

# 添加字幕
ffmpeg -i video_merged.mp4 \
  -vf "subtitles=subtitles.srt:force_style='Fontsize=28,PrimaryColour=&H00FFFF,BackColour=&H80000000'" \
  -c:a copy video_with_subs.mp4

# 合并配音
ffmpeg -i video_with_subs.mp4 -i narration.mp3 \
  -c:v copy -c:a aac -map 0:v:0 -map 1:a:0 -shortest \
  video_final.mp4
```

## ⚠️ 技术要点

### 关键帧 Prompt 设计

**错误示例**（抽象描述）:
```
"剪影对峙，拳头碰撞特效"
```
结果：AI 生成无关的动漫角色

**正确示例**（具体描述）:
```
"Two middle-aged Asian men sitting at wooden table outdoors, 
rain drops falling from eaves, warm yellow light on faces, 
cinematic portrait, 1920x1920"
```

结果：准确生成目标场景
